# Toda Fare Calculator PRO

MCSN AppFactory • Deepseek Batch (App #3)

- Screens: Home / Input / Resulta / Tapos Na
- Logic: Base + Distansya x Rate
- Offline, mobile-first, vanilla JS (localStorage)

## Install (PWA)
I-serve ang folder na ito (hal. `python3 -m http.server`), buksan sa Chrome, tapos **Add to Home Screen**.
